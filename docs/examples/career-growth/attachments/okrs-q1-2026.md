# OKRs - Q1 2026 (Engineering Platform Team)

## Objective 1: Improve platform reliability
- KR1: Reduce P1 incidents from 4/month to 2/month
- KR2: Achieve 99.9% uptime on payment and auth services
- KR3: All critical services have runbooks and on-call rotation by end of Q1

## Objective 2: Decouple core services for independent scalability
- KR1: Extract notification delivery into a standalone service
- KR2: No synchronous cross-service calls in the critical request path
- KR3: Each core service deployable independently without coordination

## Objective 3: Accelerate engineering velocity
- KR1: Reduce average PR review time from 2 days to 6 hours
- KR2: New engineers productive (first PR merged) within 5 days of starting
- KR3: 80% test coverage on payment and auth modules
