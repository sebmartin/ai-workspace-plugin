# Company Values

## Move with Urgency
Ship things. Bias toward action over analysis paralysis. When something is broken, fix it now and document later.

## Own the Outcome
Don't hand off problems. If you see it, you own it until it's resolved or explicitly handed to someone else. This includes cross-team issues.

## Build for Others
Write code, docs, and tools as if the next person is a stranger who needs to understand your reasoning. Clarity is a feature.

## Raise the Bar
Leave things better than you found them. Code quality, team process, onboarding docs -- all of it.

## Default to Transparency
Share context early and broadly. Surprises at the end of a project are a process failure, not a delivery strategy.
